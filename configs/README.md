# 歷史探索實驗設定（非最終論文正式設定）

此資料夾的 YAML 屬於較早期的研究配置，可能採 **2008–2014 訓練、2015–2017 驗證、2018–2025 測試**，並記錄單邊 5 bps 成本或其他影像通道設計。

**最終論文**使用 2000–2007 年估計（其中 70% 訓練、30% 驗證）及 2008–2025 年樣本外評估；主要貢獻是 RankNet 成對排序與**完整價格圖像＋每日單日報酬率**雙通道模型。

| 檔案 | 現有內容 | 與正式論文的差別 |
|---|---|---|
| [baseline_ohlc.yaml](baseline_ohlc.yaml) | 舊版單通道基準配置 | 期間、成本與最終論文估計不同 |
| [chen_dual_channel.yaml](chen_dual_channel.yaml) | OHLC＋均線／報酬＋成交量配置 | **不是**正式論文的雙通道資訊配置 |
| [chip_3ch.yaml](chip_3ch.yaml) | 三大法人籌碼通道探索配置 | 不屬最終論文核心路徑 |

**請勿使用這些 YAML 執行後，宣稱所得輸出可重現正式論文表 4-1 至 4-4。** 公開 `src/train.py` 目前只有設定與執行環境的示意入口，並沒有完整訓練流程。
