## 解讀原則

- **示意圖不是實際模型輸入：** 雙通道示意圖使用合成數值。正式研究輸入的是日期與水平位置對齊的灰階圖像，且兩個通道共同送入一個 CNN。
- **RankNet 三次訓練不可與分類基準逐次配對：** 模型尚未完成嚴格同條件逐次配對的正式檢定。
- **受控比較只使用表 4-3：** 年化報酬差與夏普比率兩張比較圖皆使用同一 W20H5 核心受控比較，避免跨批次混用 49.39%、57.90%。
- **D10−D1 不是實際可交易獲利：** 主要回測未完整納入交易成本、實際成交條件及放空限制；正式統計顯著性檢定亦未完整執行。

原始資料參考正式提交的 2026 年碩士論文《基於卷積神經網路之臺股雙通道價格圖像投資策略》。更多背景請見 [首頁](../../README.md) 及 [版本對照](../thesis_alignment.md)。
