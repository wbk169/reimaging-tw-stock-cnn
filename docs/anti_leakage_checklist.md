# 資料外洩與前瞻偏誤檢查清單

**用途：** 提供程式或實驗重現時的檢查項目。**未勾選表示尚未在公開儲存庫中逐項核驗**，不能當作所有檢查均已通過的證明。

## 時間資訊

- [ ] 所有輸入資訊的最晚日期為形成日 `t`（含形成日），不包含 `t` 之後的價格或成交量。
- [ ] 未來 `t+H` 收盤價只用於標籤與事後績效評估。
- [ ] 視窗與標籤範圍完整，排除長期停牌等造成實際日曆跨度異常的樣本。
- [ ] 2008–2025 年測試期不進入模型參數估計。
- [ ] 在測試結果中選代表性設定所造成的資料窺探／選擇偏誤已清楚揭露。

## 資料品質與表示方式

- [ ] 依「股票代碼－日期」確認重複、缺漏、無限大及基本 OHLC 價格關係。
- [ ] 圖像縮放只使用每個形成日已知的觀察窗資訊。
- [ ] 日報酬第二通道與價格圖像第一通道完全按交易日對齊。
- [ ] 報酬顯示裁切（如 ±10%）只改變圖像柱高，不改動原始報酬標籤。

## 模型比較與交易假設

- [ ] 實驗批次、初始化種子、樣本期間與資料切分完整記錄。
- [ ] 非完全逐次配對的模型結果不作顯著性或因果宣稱。
- [ ] 記錄非重疊投資組合形成方式與評估指標。
- [ ] 區分研究型 D10−D1 報酬與實際成交、借券及交易成本可行性。
- [ ] 不把歷史探索性 `reports/` 結果當成最終論文數據。
