# 資料集與切分（最終碩士論文）

本頁以 2026 年 7 月完成的正式論文第 3.2 節與表 3-2 為準；儲存庫中舊版籌碼實驗不屬於正式論文主實驗。

## 資料來源與規模

- **來源：** 臺灣經濟新報（TEJ），臺灣上市櫃股票日頻資料，還原權值價格口徑。
- **期間：** 2000-01-01 至 2025-12-31。
- **規模：** 1,898 檔股票，約 692 萬筆股票－日期觀測。
- **原始欄位：** 股票代碼（論文以 `ticker` 表示）、交易日期（`date`）、`open`、`high`、`low`、`close`、`volume`。
- **衍生欄位：** 移動平均線、每日報酬率與未來 H 日報酬／方向標籤（由歷史資料計算，不是額外的授權原始欄位）。

## 訓練、驗證與樣本外評估

| 用途 | 期間 | 說明 |
|---|---|---|
| 模型估計 | 2000–2007 | 估計期間內 70% 用於訓練，30% 用於驗證與提前停止 |
| 樣本外測試 | 2008–2025 | 不參與模型參數估計 |
| 補充擴張視窗檢查 | 從 2008 年開始逐年推進 | 初始採 2000–2006 訓練、2007 驗證；與固定切分主結果分開 |

估計期間內的訓練／驗證樣本分配**不能視為完整消除金融時間相依性**。正式論文的主結果採固定切分，而非 GitHub 舊設定中的 2018–2025 主要測試期。

## 資料品質與避免前瞻資訊

以「股票代碼－交易日期」作為主鍵，檢查重複、缺漏、無限大、OHLC 價格上下界及視窗資料是否完整。若無法取得完整 W 日觀察資料或 H 日後報酬標籤則排除樣本。

影像只能包含截至形成日 `t` 已知的價格與成交量；未來 `t+H` 收盤資料只用於產生標籤和計算評估報酬。正式論文核心實驗**未加入最低股價、最低成交金額或最低活躍率門檻**。
