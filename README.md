# 基於卷積神經網路之臺股雙通道價格圖像投資策略

**A CNN-Based Dual-Channel Price-Image Investment Strategy for Taiwan Stocks**

中原大學資訊管理學系｜碩士學位論文｜2026 年 7 月  
**研究領域：** 深度學習、金融資料分析、價格圖像、股票排序

本研究將臺灣股票的歷史價格與成交量轉換為圖像，透過卷積神經網路（CNN）學習價量特徵，探討**成對排序學習**與**每日報酬率獨立通道**對樣本外選股排序的影響。

> **儲存庫定位：** 這是最終論文的研究介紹與部分公開程式展示。部分 `src/`、`configs/` 與 `reports/` 來自早期探索性實驗，**尚不能直接重現正式論文全部實驗**；相關差異見 [研究版本對照](docs/thesis_alignment.md)。

## 研究貢獻（Highlights）

- **臺股價格圖像基準：** 使用 2000–2025 年臺灣上市櫃股票日資料，比較 3 種觀察窗 × 3 種預測期，共 9 組模型設定。
- **排序目標改良：** 導入 RankNet 成對排序，直接學習同一天不同股票的相對未來報酬順序。
- **輸入表徵改良：** 保留 OHLC、移動平均線與成交量的完整價格圖像，另外加入每日單日報酬率通道，形成雙通道 CNN 輸入。

**核心結果（論文表 4-3）：** 在 W20H5 設定下，雙通道模型的 D10−D1 高低分組**年化報酬差**由 **57.90%** 變為 **74.08%**，相差 **16.18 個百分點**。這是特定樣本外歷史回測的描述性比較，**不是實盤收益，也未完成正式統計顯著性檢定**。

## 研究方法（Methodology）

```text
TEJ 臺股日頻價量資料（OHLCV）
            ↓
    資料品質檢查、樣本篩選
            ↓
      價格圖像建構
            ↓
  ┌────────────────────┬───────────────────────────┐
  │ 路徑 A：單通道 CNN  │ 路徑 B：雙通道 CNN         │
  │ 分類基準 → RankNet │ 完整價格圖 + 每日報酬通道 │
  └────────────────────┴───────────────────────────┘
            ↓
     樣本外股票預測分數
            ↓
     同日分數排序 D1～D10
            ↓
    分類與投資組合績效評估
```

**雙通道輸入（論文圖 3-3、3-4）：**

| 通道 | 內容 | W20 主設定 |
|---|---|---|
| 第一通道 | 開盤、最高、最低、收盤（OHLC）、移動平均線、成交量 | 1 × 64 × 60 |
| 第二通道 | 與第一通道逐日對齊的每日單日報酬率柱狀圖 | 合併後 2 × 64 × 60 |

第一通道**沒有移除成交量**；第二通道**不是 20 日累積報酬率**。這個配置不同於舊版 `configs/chen_dual_channel.yaml` 所描述的探索性架構。

模型先輸出未來報酬方向分數，或由 RankNet 輸出相對排序分數；再於同一形成日依分數由低至高分為 D1～D10，檢視最高與最低分組的差距及風險指標。

## 資料與實驗設定（Dataset & Setup）

| 項目 | 最終論文的主要設定 |
|---|---|
| 資料來源 | 臺灣經濟新報（TEJ），臺灣上市櫃股票日頻資料 |
| 資料期間 | 2000–2025 年 |
| 研究規模 | 1,898 檔股票、約 692 萬筆股票－日期觀測（表 3-2） |
| 模型估計 | 2000–2007 年；其中 70%／30% 作訓練與驗證 |
| 樣本外評估 | 2008–2025 年，不參與模型參數估計 |
| 觀察／預測期間 | W ∈ {5, 20, 60}、H ∈ {5, 20, 60} 個交易日 |
| 核心比較 | W20H5：過去 20 日預測未來 5 日 |
| 評估 | AUC、準確率、D1～D10 分組、年化報酬、夏普比率、最大回撤 |

W20H5 是從九組時間尺度結果中選出的**代表性設定**，不是事前指定或經檢定證明最佳的參數。估計期間內的訓練／驗證切分也仍可能受到時間相依性的影響。

## 主要實驗結果（Results）

### 1. 價格圖像基準與 RankNet

| 論文出處 | W20H5 模型／實驗 | D10−D1 年化報酬差 |
|---|---|---:|
| 表 4-1 | 九組時間尺度中的價格圖像分類基準（單批次） | 49.39% |
| 表 4-2 | RankNet 成對排序（三次獨立訓練平均） | 59.77% |

上述兩列是**不同實驗彙整口徑**，不是完全逐次配對的比較，不能以差異推論顯著改善。

### 2. 每日報酬通道受控比較

**論文表 4-3｜W20H5，三次獨立訓練的彙整平均**

| 指標 | 價格圖像分類基準 | 獨立日報酬雙通道 |
|---|---:|---:|
| AUC | 0.5435 | **0.5527** |
| 準確率 | 0.5305 | **0.5364** |
| D10 年化報酬 | 42.61% | **50.39%** |
| D10−D1 年化報酬差 | 57.90% | **74.08%** |
| D10−D1 夏普比率 | 5.65 | **6.34** |
| D10−D1 最大回撤 | −7.96% | **−6.36%** |

這組比較的報酬差距增加 16.18 個百分點，但不同 W／H 設定不一定呈現相同改善方向；研究結論必須連同限制閱讀。更多數據及出處見 [正式論文結果對照](docs/thesis_alignment.md)。

## 快速開始（Quick Start）

本儲存庫提供**不需要 TEJ 資料的示範圖像產生程式**。執行下列指令可使用隨機合成的 OHLC 資料產生簡化示例：

```bash
git clone https://github.com/wbk169/reimaging-tw-stock-cnn.git
cd reimaging-tw-stock-cnn
python -m pip install numpy matplotlib
python scripts/make_sample_image.py
```

輸出位置：`outputs_sample/sample_images/sample_001.png`。此示例只繪製 OHLC 線條，**不含最終論文圖像所需的全部均線、成交量與第二通道**。

完整依賴套件列於 `requirements.txt`。目前 `src/train.py` 只展示設定與環境檢查流程，**不會實際訓練或輸出正式論文模型**。更多資訊請見 [可重現性與執行範圍](docs/reproducibility.md)。

## 可重現性與限制（Reproducibility & Limitations）

- **資料授權：** 原始 TEJ 授權行情資料未公開，無法使用本儲存庫獨立重現全部數值。
- **公開程式範圍：** 目前沒有與最終論文逐項對應的完整資料管線、雙通道與 RankNet 訓練程式、模型權重及全部預測檔案。
- **統計推論：** 尚未完成正式多重假設檢定與完整統計顯著性檢定，不能宣稱策略優勢已被證明。
- **實務交易：** 主要投資組合結果沒有完整納入手續費、稅負、滑價、借券、流動性與市場衝擊；D10−D1 主要是排序能力的診斷指標。
- **版本區隔：** `reports/main_results.csv`、`reports/walk_forward_*` 與籌碼配置屬於其他批次的歷史實驗，**不得與表 4-3 主結果混合比較**。
